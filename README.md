# Run
Run `python -m http.server 8000` in your command line of choice.

# GitHub Pages
This project can be deployed for free with GitHub Pages because it is a static map application.

## Deployment steps
1. Create a GitHub repository and push this project into it.
2. In the repository settings, go to **Pages**.
3. Set the source to the `main` branch (or `master`) and the root folder (`/root`).
4. Save the settings.
5. Open the published URL, for example:
   `https://USERNAME.github.io/REPO_NAME/map.html`

## Optional
- Rename `map.html` to `index.html` to publish the map directly at `https://USERNAME.github.io/REPO_NAME/`.
- If you prefer, use CDN links for Leaflet instead of local `leaflet.css` and `leaflet.js` files.
